The current tests cannot detect an error that shares a binder address between recursive activations or restores an outer frame too early. This is a confirmed coverage and claim defect, not evidence that the implementation has either error. A narrow correction is to add a native-admitted recursive fixture with no nonfixed owner live across the back edge. Use different source values at each depth, check distinct live binder addresses, and check the caller's original image after the child returns. Add a live frame/top check and a control that fails for shared binder storage. Run the same fixture at O0/O2 under the native reference, Node, and Wasmtime in a later authorized validation unit. Until then, qualify or remove the recursion coverage claim. No production change is justified by this finding.
